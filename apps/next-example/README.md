# Next.js example

A Next.js App Router app using `@morphfx/react`: a play/pause toggle (reversible mid-morph), a shape cycler (interruptible), a slider-controlled morph, and a `<MorphPath>` rendered by a Server Component.

```sh
pnpm install
pnpm --filter @morphfx/core --filter @morphfx/react build
pnpm --filter @morphfx/next-example dev
```

Then open http://localhost:3000.
