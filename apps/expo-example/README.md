# Expo example

An Expo app using `@morphfx/react-native`: a play/pause toggle (reversible mid-morph), a shape cycler (interruptible), and a morph driven by a shared value on the UI thread.

```sh
pnpm install
pnpm --filter @morphfx/core --filter @morphfx/react-native build
pnpm --filter @morphfx/expo-example start
```

Then press `i` (iOS simulator), `a` (Android emulator) or `w` (web), or scan the QR code with Expo Go.
